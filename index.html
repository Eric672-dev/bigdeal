Données EODHD — comment c'est configuré

La clé API EODHD n'est plus saisie ici : elle est configurée une seule fois côté serveur (Netlify → Site configuration → Environment variables → EODHD_API_KEY), pour que le navigateur n'ait jamais à y accéder directement. Si les données ne se chargent pas, vérifie cette variable d'environnement.

Pas encore de clé ? Crée un compte sur eodhd.com — abonnement « EOD Historical Data » à partir de 19,99 $/mois (cours de clôture réels, historique, dividendes ; pas de temps réel à ce palier).

Publication Résultat

Objectif : profiter du mouvement de cours autour d'une publication de résultats, sans subir la volatilité de l'annonce elle-même.

✕ La veille de l'annonce : ne pas acheter. Trop risqué — le cours peut faire un gap dans n'importe quel sens à la publication. À la place, placer un ordre avec un seuil de déclenchement à la hausse : l'achat ne s'exécute que si le cours dépasse ce seuil après l'annonce.
✓ Le lendemain de l'annonce : acheter. Une fois la réaction du marché connue et le seuil franchi, on entre en position — jamais avant.
